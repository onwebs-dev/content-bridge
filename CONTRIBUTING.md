# Contributing | راهنمای مشارکت

## English

Thank you for helping improve Content Bridge.

1. Fork the repository and create a focused branch.
2. Keep Persian and English content aligned when changing user-facing copy.
3. Preserve RTL/LTR behavior, accessibility, responsive layouts, and local assets.
4. Do not commit SMTP passwords, tokens, `.env` files, or customer data.
5. Run `npm test` before opening a pull request.
6. Explain the problem, the change, and how you verified it in the pull request.

For larger product or architecture changes, open an issue first so the approach can be discussed.

## فارسی

از مشارکت شما در بهبود Content Bridge ممنونیم.

1. مخزن را Fork کنید و یک شاخه مشخص برای تغییر بسازید.
2. هنگام تغییر متن‌های رابط، نسخه فارسی و انگلیسی را هماهنگ نگه دارید.
3. رفتار RTL/LTR، دسترس‌پذیری، طراحی واکنش‌گرا و دارایی‌های محلی را حفظ کنید.
4. رمز SMTP، توکن، فایل‌های `.env` یا اطلاعات مشتری را commit نکنید.
5. قبل از بازکردن Pull Request دستور `npm test` را اجرا کنید.
6. مسئله، تغییر انجام‌شده و روش بررسی آن را داخل Pull Request توضیح دهید.

برای تغییرات بزرگ محصول یا معماری، ابتدا یک Issue باز کنید تا درباره مسیر اجرا هماهنگ شویم.
